## 修改

1. 在进入文件 API 前拒绝含空字符的路径，返回 HTTP 400。
2. 将服务器构造函数独立导出以便真实 HTTP 测试，命令行启动方式和仅监听本机的行为保持兼容。
3. 增加 3 项 HTTP 回归测试，覆盖正常页面和脚本、编码空字符及错误转义、错误请求后的存活性、HEAD、隐藏文件、路径穿越和不支持的方法。
4. 版本从 1.0.0 更新为 1.0.1，并更新界面版本、README 和 CHANGELOG。
